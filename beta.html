03 / SOMETHING TO DECLARE?

File a report.

Crashes, confusing instructions, broken interactions, save problems or a desk behaving suspiciously: your observations help improve the game.

Check existing issues first, then include what happened, what you expected, steps to reproduce it, your game and Windows versions, and any helpful screenshots or video.

FREQUENT ENQUIRIES

Before you ask.

Where can I find known issues and changes?

Read the release notes on GitHub Releases and check existing issues before submitting a report.

Can I save my progress?

Yes. Floppy//144 supports manual saving, loading and automatic saving. Press Esc to open GDR Session Control. You can adjust autosave frequency in Settings. Progress, your profile and settings are stored locally.

Will my saves work after an update?

Beta updates may occasionally require a fresh game session. Any such requirement will be noted with the release. Check those notes before updating.

Do I need to install anything?

No installer is required. Extract the Windows beta ZIP and run Floppy144.exe from the extracted folder. Do not try to launch it from inside the ZIP.
